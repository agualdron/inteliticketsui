# Untitled UI React source components

The local `Button`, `Input`, `TextArea`, and `Badge` primitives follow the open-source Untitled UI React base-component patterns and React Aria APIs, adapted to this project's tokens and route links. Untitled UI React publishes these components as copy-in source under MIT rather than as a component package.

Upstream source and license: https://github.com/untitleduico/react

The MIT notice is included in `LICENSE`. These local adaptations are not the paid Untitled UI Pro components.
